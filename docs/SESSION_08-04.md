- Фікс: додано колонку `previous_status` в БД (міграція), при архівуванні зберігаємо попередній статус, при розархівуванні — відновлюємо

## Що треба зробити

### Найближче (наступна сесія)

#### Вкладення (чеки) — головний пріоритет
Послідовність реалізації:
1. Flask endpoint для upload/download файлів, зберігання в `uploads/` локально
2. Поле `storage_type: 'local' | 'gdrive'` в таблиці `attachments` — щоб потім не переробляти під Google Drive
3. Прив'язка файлів до запису при збереженні (форма вже має upload-зону, але файли нікуди не йдуть)
4. Підтримка HEIC/HEIF — конвертація через `heic2any` в браузері
5. Перегляд файлів в деталях запису (lightbox для фото, вбудований PDF viewer)
6. Кнопка "+ Додати файл" в деталях існуючого запису (зараз заглушка)
7. Google Drive інтеграція — OAuth + API (заготовки вже є в index.html)

#### Експорт — відкладені питання
- Якість PDF (після вкладень)
- Вибір полів для експорту (toggleable кнопки/чіпи) — обговорено, реалізація відкладена
