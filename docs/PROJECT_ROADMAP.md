## Найближче (активна розробка)

### Виправлення поточних багів

- [ ] Дашборд: оновлення суми після додавання запису
- [ ] Редагування: відновлення значень полів "Компанія" та "Платіжний інструмент"
- [ ] Статус: коректне збереження (зараз завжди `no-return`)
- [ ] Архів / кошик: реалізація функціональності
- [ ] Налаштування: кнопки деактивації компаній та інструментів
- [ ] Вкладення: відображення фідбеку після завантаження файлу

### Тестування

- [ ] Повноцінне локальне тестування всього функціоналу перед будь-якими деплой-кроками

## Середньострокові плани

### Архітектура та інфраструктура

- [ ] **Docker контейнеризація** — упаковка застосунку в Docker-образ
- [ ] **Docker Hub** — публікація образу для портативного запуску
- [ ] **Рефакторинг** — якщо multi-file структура ще не завершена

### Зберігання файлів

- [ ] **Google Drive інтеграція** — зберігання вкладень (чеків, інвойсів) на Google Drive замість локального сховища
  - Розглядаються варіанти: Google Drive як файлове сховище + SQLite як база (Variant A), повністю Google-based (Variant B), або IndexedDB + Drive sync hybrid (Variant C)
  - Остаточне рішення ще не прийнято

### Авторизація

- [ ] **Google OAuth** — вхід через Google акаунт як альтернатива/заміна локальній авторизації

### Import Inbox

- [ ] Окрема зона для "вхідних" необроблених документів
- [ ] Можливість переглянути, розпізнати і перетворити на запис

### OCR

- [ ] Автоматичне розпізнавання даних з фото та сканів чеків
- [ ] Автозаповнення полів запису після сканування

### Експорт

- [ ] Вивантаження даних у **XLSX** (Excel)
- [ ] Вивантаження даних у **CSV**

### Розширення можливостей

- [ ] Підтримка додаткових валют
- [ ] Додаткові мови інтерфейсу
