# Програма для рахунків
**Назва робоча:** Reimbursement App

Легенда: `+` виконано · `-` не виконано · `~` частково / в процесі

---

## Призначення аплікації

Аплікація потрібна для особистого використання на iPhone, щоб зберігати чеки, рахунки, інвойси та інші підтвердження витрат, які були оплачені або приватно, або фірмовою карткою. Основна задача — мати всі документи в одному місці, бачити їх в самій аплікації та паралельно зберігати їх у Google Drive, а також відслідковувати повернення коштів по витратах, які були оплачені приватно.

| # | Вимога | Статус | Коментар |
|---|--------|--------|----------|
| 1 | Зберігати чеки, рахунки, інвойси | `+` | Записи з вкладеннями (фото/PDF) |
| 2 | Оплачено приватно або фірмовою карткою | `+` | pay_type: private / company |
| 3 | Всі документи в одному місці | `+` | Список + детальний перегляд |
| 4 | Зберігання в Google Drive | `-` | Заплановано (наступний етап) |
| 5 | Відслідковування повернень коштів | `+` | return_events, залишок, статуси |

---

## Основні сценарії використання

**Сценарій 1:** оплата приватно (картка / готівка) → компанія повертає кошти

| # | Вимога | Статус | Коментар |
|---|--------|--------|----------|
| 1 | Тип оплати "приватна" | `+` | pay_type = private |
| 2 | Метод оплати: картка або готівка | `+` | pay_method: card / cash |
| 3 | Відслідковування повернення | `+` | return_events, статуси waiting/partial/done |
| 4 | Залишок до повернення | `+` | Автоматичний розрахунок remainder |

**Сценарій 2:** оплата фірмовою карткою → повернення не потрібне, документ зберігається

| # | Вимога | Статус | Коментар |
|---|--------|--------|----------|
| 1 | Тип оплати "фірмова картка" | `+` | pay_type = company |
| 2 | Документ зберігається в системі | `+` | Повноцінний запис із вкладеннями |
| 3 | Без блоку повернення | `+` | Return section прихований для company |

## Логіка для приватно оплачених витрат

| # | Вимога | Статус | Коментар |
|---|--------|--------|----------|
| 1 | Сума, яку мають повернути | `+` | поле to_return |
| 2 | Сума, яку вже повернули | `+` | поле returned |
| 3 | Залишок до повернення | `+` | поле remainder, автоматичний розрахунок |
| 4 | Дата повернення | `+` | в кожній події повернення |
| 5 | Декілька часткових повернень | `+` | таблиця return_events |
| 6 | Метод повернення (необов’язково) | `+` | необов’язкове поле в формі |

Відображення прикладу з ТЗ (500€):

| # | Вимога | Статус | Коментар |
|---|--------|--------|----------|
| 1 | Показати запрошену суму | `+` | to_return = 500€ |
| 2 | Показати повернуто / загальну суму | `+` | returned = 200€, прогрес-бар |
| 3 | Показати залишок | `+` | remainder = 300€ |
| 4 | Автостатус "частково повернуто" | `+` | автоматично при partial return |
| 5 | Автостатус "повністю повернуто" після 500€ | `+` | remainder = 0 → status = done |

## Суть аплікації

Особистий трекер чеків та інвойсів для двох сценаріїв: приватна оплата з подальшим поверненням коштів від компанії та оплата фірмовою карткою. Функції: фото/файли, ручне введення даних, зберігання локально + Google Drive (наступний етап), відстеження статусів і повернень, фільтри, дашборд, експорт XLSX/CSV, захист Face ID / PIN (iOS-етап).
