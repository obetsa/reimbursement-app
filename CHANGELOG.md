# Changelog — Docker Hub версії (`obetsa/reimbursement-app`)

> Що приблизно було в кожному образі. Для v1-v4 — реконструйовано по даті пушу і git-історії (точний коміт невідомий, бо в образ не вшивався git SHA — див. примітку внизу). Для v5+ — точно, бо версійність з v5 ведеться свідомо.

## latest (07.07.2026, коміт `14dbd4e`)
Поточний код гілки `company-expenses`. Відносно v5:
- Manager, що створив компанію, автоматично отримує до неї доступ (раніше сам її не бачив)
- Компанії сортуються по даті створення (було: рандомно через дублікати `sort_order`)
- Неактивні компанії зникають з дропдаунів у "Витрати по компаніях" і "Розрахунки між компаніями" (раніше — тільки в формі документів)
- Фікс 500-ки при завантаженні вкладення (`attachments.storage_type/drive_id` — колонки видалені міграцією, код досі на них посилався)

---

**Примітка для майбутнього:** зараз немає способу точно перевірити, який git-коміт відповідає якомусь старому тегу (v1-v4) — образ не містить git SHA. Якщо це важливо — можна додати `LABEL org.opencontainers.image.revision` в `Dockerfile` з git-хешем на момент білду, і тоді `docker inspect` завжди покаже точний коміт. Не робив це зараз без окремого прохання.
